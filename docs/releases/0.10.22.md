# YaJarvis 0.10.22

- Яндекс Диск для обучения слова активации (плагин «Обучение слова» 1.3.0): ручная настройка WebDAV заменена на подключение Яндекс Диска в одну кнопку по коду на `ya.ru/device` (отдельная папка `Приложения / YaJarvis`, без доступа к остальным файлам). Короткие записи и длительный фон автоматически выгружаются на Диск и освобождают флешку колонки, прослушивание работает напрямую из облака с RAM-кешем и предзагрузкой следующей записи, разметка («Джарвис» / «Не Джарвис» / удаление) переносит файлы прямо на сервере Яндекса, а «Скачать записи» потоково собирает единый ZIP-архив из локальных и облачных клипов.
- Качество звука YouTube (плагин YouTube 1.1.3): воспроизведение переведено на нативное стерео 48 кГц Opus (`-c 2`), добавлена поддержка 256 кбит/с (`itag 774`) с выбором лучшего не-DRC потока по реальному битрейту, а базовый уровень громкости музыки поднят с `0.8` до `0.95` (+1.5 дБ) с округлением сэмплов.
- Качество голоса ChatGPT: 5-мс лимитер переписан на скользящее удержание пика по всему окну задержки (убраны клиппинг и срывы на переходах через ноль), а в WebRTC SDP-оффере OpenAI теперь запрашивается полное качество (`maxplaybackrate=48000;maxaveragebitrate=128000`) и `OPUS_SIGNAL_VOICE` для микрофона.
- YouTube — ускорение запуска и аккаунты: JS-решатель плеера кешируется на диске (`player-cache.json.gz`) с автосбросом при `403`, исправлено определение имени, `@handle` и почты для TV-аккаунтов YouTube, при выходе из аккаунта очищаются куки, обновлены подписи в панели подключений.
- Документация для разработчиков: добавлена спецификация `docs/PLUGIN-AGENT.md` для ИИ-агентов разработки плагинов и расширен разбор частых ошибок Lua в `docs/PLUGINS.md`.
