# YaJarvis 0.10.24

- Переключение профилей ассистента голосом (`#36`):
  - Добавлены быстрые команды («включи детский профиль», «переключи профиль на …») и инструмент `switch_profile` с подбором профиля по имени, ID и словоформам, обновлением LED-подсветки и мягким завершением диалога после подтверждения.
- Обучение слова активации (плагин `training` `1.4.0`, `#19`):
  - Добавлена отключаемая голосовая разметка срабатываний (`review_current_wake` — «тебе послышалось» / «правильно услышал») с защитой от дублей по `wake_id` и переключателем **«Разметка голосом»** в веб-панели (по умолчанию выключен).
- Веб-панель и отчётность:
  - На вкладке **«Логи»** добавлена кнопка **«Отчёт для баг-репорта»** (`GET /api/logs/report`) — скачивание `.txt`-отчёта с диагностикой системы и хвостами `jarvisd.log` / `maind.log` / `mediad.log` с автоматической очисткой ключей, токенов и ссылок VLESS (`[REDACTED]`).
  - Добавлена корневая инструкция [`AGENTS.md`](../../AGENTS.md) для ИИ-агентов и формы GitHub Issues (`.github/ISSUE_TEMPLATE/`).
